# Functional audit — 20 October 2026

Version after fixes: **0.3.1**. This is an automated behavioral and source review
performed during development, not an external third-party certification.

## Findings and fixes

| Finding | Impact | Resolution |
| --- | --- | --- |
| “Всё” did not explain the difference between loaded history and lifetime history. With 90 loaded days it looked identical to “90Д”. | Misleading control | Renamed to “Вся загрузка”; added available date range, filter explanation and guidance to the 365-day API lookback. Verified 7 → 30 → 90 → all and 365 → 90 → all using observation counts. |
| Manual refresh reused cached responses without making new requests. | Stale data could look refreshed | Explicit refresh now bypasses the app cache while respecting request spacing, timeouts and quota cooldown. Provider caching/delay still applies. |
| Refresh reset a selected 7/30/90-day chart filter. | Unexpected view change | Refresh preserves the filter. Changing the API lookback deliberately resets it to all loaded history. |
| CSV import, demo loading and asset changes could overlap an API load. | Conflicting state and possible capacity violation | Mutating controls lock during asynchronous operations. Drop import is guarded too. Added cancellation; it aborts and clears the API client while retaining observations already received. |
| Partial refreshes could leave different lookbacks while showing a generic success message. | Confusing provenance | Explicit partial-success status; each active online asset shows requested history length and fetch time; JSON includes requested lookback and discarded-row count. |
| Mobile CSS hid the CSV format/template control and could override a hidden text button. | Inaccessible/misleading controls | Format control available on mobile; explicit `[hidden]` rule preserves hidden states at all widths. |
| Metric cards could overflow a 320 px viewport. | Horizontal page scrolling | Constrained grid tracks and wrapped long metric text. Checked 320, 390, 768 and 1280 px widths. Tables retain their own horizontal scrolling. |
| When no common period existed, quality silently used the active asset’s entire history. Warning color could remain after clearing data. | Mismatched statistics | Quality now reports insufficient common observations and clears stale warning state; excluded API rows also trigger a warning. |
| Importing a CSV reselected previously unchecked real assets. | Unintended comparison changes | Existing selection is preserved; imported series selected; demos deselected. |
| Malformed successful API payloads stayed cached for five minutes. | Repeated failures after provider recovery | Invalid history/search payloads are evicted. Verified retry succeeds after a malformed response. |
| Source `index.html` brand link could reload the page and erase the in-memory workspace. | Data loss on navigation | Brand uses an in-page link in source and standalone. |
| “Последняя цена” could refer to a historical comparison endpoint. | Ambiguous metric | Label changed to “Цена на конец периода”. |

## Validation

- **25 Node tests**, including analytics, cache/refresh, invalid data, 401/429,
  plan/network failures, timeout, disconnect and credential isolation: passed.
- **9 Python CLI tests**, including decimal arithmetic and validation: passed.
- **Three Chromium browser suites**: passed:
  - offline dashboard: CSV import/errors, demo, periods, comparison, keyboard,
    all four exports, mobile, standalone and no unintended network requests;
  - CoinGecko workflow: header-only key, default assets, exact-ID search, history
    lookbacks, refresh, provenance, rate/auth failures, disconnect and reload;
  - behavioral audit: period counts, new refresh requests, pointer/keyboard,
    asset selection, safe rendering of adversarial names, partial/network
    failures, all exports, dialogs/CSV template, mobile/tablet, capacity,
    concurrent-import guard, cancellation and independent `file://` operation.
- Desktop/mobile screenshot inspection: passed. Preview screenshots use clearly
  labeled fictional demo data.

All API responses in the regression browser suites are explicitly synthetic
fixtures with a placeholder key. Earlier real BTC/ETH/SOL integration was tested
separately; this audit does not claim continuous availability of CoinGecko or
repeat that network test. No real key is included in this repository or bundle.

## Useful scope and remaining limits

The app supports small price-history investigations: compare relative price
changes, inspect sampled drawdowns, inspect sampling gaps and export a report
with sources and retrieval time. CoinGecko coin search does not cover arbitrary
onchain contracts/DEX pools. It does not assess token safety, predict returns,
stream exchange prices or maintain a portfolio ledger. “All” means all loaded
observations within the common period; it never promises lifetime history.

Browser validation here covers Chromium; it is not a full browser-compatibility,
accessibility or penetration-testing certification. Browser computations use
floating-point numbers and retain data/key only until page close/reload.
